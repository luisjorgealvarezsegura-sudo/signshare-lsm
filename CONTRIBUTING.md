# Contributing to SignShare LSM

Thank you for helping build SignShare LSM.

## Development Rules

- Keep screens simple and accessible.
- Use clear labels for buttons.
- Do not claim full sign-language translation unless the feature works.
- Treat uploaded sign videos as community contributions that should be moderated.
- Keep the competition demo focused on upload, search, and viewing community examples.

## Before Committing

When Flutter is available locally, run:

```bash
flutter pub get
flutter analyze
flutter test
```

If Flutter is not installed locally, push to GitHub and let GitHub Actions run these checks.
