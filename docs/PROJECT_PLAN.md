# SignShare LSM Project Plan

## MVP Goal

Build a community-powered sign language dictionary where users can search a word and view multiple uploaded videos for that word.

## Phase 1

- Home screen
- Navigation
- Placeholder screens
- Widget tests
- GitHub Actions Android build

## Phase 2

- Search screen
- Local sample data
- Video result cards
- Demo word list

Suggested demo words:

```text
hola
gracias
agua
comida
ayuda
mamá
papá
escuela
amigo
baño
```

## Phase 3

- Upload screen
- Firebase Auth
- Firestore metadata
- Firebase Storage videos

## Phase 4

- Recognition prototype
- MediaPipe landmark extraction
- Similarity matching
- Top 3 matches
